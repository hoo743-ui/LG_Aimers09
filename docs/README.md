## Repository Principle

루트의 README는 **결과와 핵심 의사결정**만 설명하고, 장기간 축적되는 실험 기록은 별도 문서로 관리합니다.

이 저장소의 목적은 단순히 최종 제출 코드만 보여주는 것이 아니라, **가설 → 실험 → 결과 → 실패 원인 → 다음 가설**의 연구 과정을 재현할 수 있게 남기는 것입니다.
